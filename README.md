# GCP & Workspace Identity Governor

Automated identity lifecycle, organizational unit (OU) governance, and least-privilege GCP IAM reconciliation engine in Python.

## Core Capabilities
- Automated user onboarding/offboarding workflows between HRIS webhooks and Cloud Identity.
- Least-privilege GCP IAM policy binding reconciliation across project hierarchies.
- Immediate access revocation and token invalidation on employee offboarding.
- Deterministic drift detection and compliance audit manifests.
